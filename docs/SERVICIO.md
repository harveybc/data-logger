# Software libre, servicio opcional

El código y los diseños de este repositorio se publican bajo **MIT**
(`LICENSE.txt`): se pueden usar, copiar y adaptar. Se ofrecen **tal
cual**, sin garantía de idoneidad para un fin particular. Quien opera
un sitio es responsable de sus decisiones (sanitarias, comerciales o
de seguridad).

Si más adelante hay un **servicio de pago** (servidor, respaldo,
soporte, alta de sitios), eso es un contrato aparte: se cobra el
trabajo de operar, no una licencia por sensor. ThingsBoard CE no cobra
por dispositivo.

Este archivo no es asesoría legal. Un abogado del país de operación
debe revisar términos del servicio y responsabilidades antes de cobrar
a terceros.
